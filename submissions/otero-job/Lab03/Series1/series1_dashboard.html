Series1 Numerical Methods Laboratory Results

An investigation of numerical convergence toward mathematical constants and functions using series approximations.

Introduction

This laboratory exercise investigates three fundamental numerical methods:

  • Numerical convergence toward e — demonstrating that the sequence (1 + 1/n)n approaches the mathematical constant e as n increases.
  • Numerical convergence toward ln(a) — showing that the difference quotient (ah − 1)/h approaches the natural logarithm ln(a) as h approaches zero.
  • Approximation of exponential functions using power series — computing ex using the Taylor series expansion with increasing numbers of terms.

Exercise 1: Convergence of (1 + 1/n)n toward e

Exercise 1
limn→∞ (1 + 1/n)n = e ≈ 2.718281828459045

Convergence Result

The sequence (1 + 1/n)n converges to the mathematical constant e as n increases. Starting from n = 1 (value = 2.0), the sequence approaches e as n is doubled repeatedly. At n = 1,048,576, the value is 2.718280532282396 with an absolute error of approximately 1.30 × 10−6.

Key Numerical Observations

  • At n = 1: value = 2.000000000000, error = 7.18 × 10−1
  • At n = 16: value = 2.637928497367, error = 8.04 × 10−2
  • At n = 1,024: value = 2.716955729466, error = 1.33 × 10−3
  • At n = 1,048,576: value = 2.718280532282, error = 1.30 × 10−6
  • The error decreases approximately linearly on a log-log scale, demonstrating steady convergence.

Exercise 2: Convergence of (ah − 1)/h toward ln(a)

Exercise 2
limh→0 (ah − 1)/h = ln(a)

Convergence Result

The difference quotient (ah − 1)/h converges to the natural logarithm ln(a) as h approaches zero. This was verified for a = 2, a = e, and a = 3. With a convergence tolerance of 1 × 10−6, all three values of a reached the required accuracy at h = 1 × 10−6.

Key Numerical Observations

  • a = 2: ln(2) = 0.693147180560; error at h = 10−6 is 2.40 × 10−7
  • a = e: ln(e) = 1.000000000000; error at h = 10−6 is 5.00 × 10−7
  • a = 3: ln(3) = 1.098612288668; error at h = 10−6 is 6.04 × 10−7
  • All three values converge to their respective ln(a) targets within the 1 × 10−6 tolerance at h = 10−6.
  • The error decreases approximately linearly with h, confirming first-order convergence.

Exercise 3: Approximation of ex Using the Power Series

Exercise 3
ex = Σn=0∞ xn / n!

Convergence Result

The power series ex = Σ(xn/n!) converges rapidly to the true value of ex. Using x = 2.0, the partial sum SN approaches e2 = 7.389056098930650. An error below 1 × 10−6 is achieved with just N = 13 terms, and machine precision (~10−15) is reached by N = 20.

Key Numerical Observations

  • Error < 1 × 10−2 achieved at N = 7 terms
  • Error < 1 × 10−4 achieved at N = 10 terms
  • Error < 1 × 10−6 achieved at N = 13 terms
  • Error < 1 × 10−10 achieved at N = 17 terms
  • Final error at N = 10,000 is 1.78 × 10−15 (machine precision)
  • The stable recurrence relation termn+1 = termn × x/(n+1) avoids factorial overflow.

Conclusions

  • Numerical approximations converge toward theoretical mathematical values. All three exercises demonstrated that carefully constructed numerical sequences and series converge to their corresponding mathematical constants and functions.
  • Decreasing step sizes improve numerical approximations. In Exercise 2, reducing h from 0.1 to 10−6 reduced the error from ~10−2 to below 10−6, confirming that smaller step sizes yield more accurate results.
  • Increasing the number of power-series terms improves accuracy. In Exercise 3, increasing N from 0 to 20 reduced the error from ~6.4 to below 10−14, demonstrating rapid convergence of the Taylor series.
  • Floating-point precision and numerical stability matter. Using the recurrence relation termn+1 = termn × x/(n+1) avoids computing huge factorials directly, which would cause overflow. This highlights the importance of numerically stable algorithms in scientific computing.
  • Convergence tolerance provides a practical stopping criterion. The 1 × 10−6 tolerance used in Exercise 2 allowed us to determine exactly when each approximation became sufficiently accurate.
